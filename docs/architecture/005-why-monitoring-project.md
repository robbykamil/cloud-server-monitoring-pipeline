# Personal Monitoring Project

## Date

2026-09-27

## Deciders

Robby Kamil

## Context

I have experience in IT Operations, but I am not able to publish my work from previous employers as part of a public portfolio. To demonstrate my skills to recruiters and potential employers, I need a project that is fully my own and publicly shareable.

## Decision

Build a monitoring platform as a personal portfolio project.

## Reasons

This project covers several skills directly relevant to a DevOps career path:

- **Monitoring** — collecting and tracking system metrics (CPU, memory, disk)
- **Alerting** — notifying when thresholds are exceeded
- **Logging** — parsing and analyzing log data
- **Automation** — scripting recurring operational tasks
- **Docker** — packaging the application for consistent deployment (see ADR-002)
- **CI/CD** — automated testing via GitHub Actions (see ADR-003)
- **Cloud deployment** — hosting on Oracle Cloud Free Tier (see ADR-004)

Together, these areas form an end-to-end demonstration of practical DevOps and IT Operations skills in a single, publicly visible project.
